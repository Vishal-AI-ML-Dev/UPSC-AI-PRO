# Plans

One plan per phase, named `phase-NN-<slug>.md`, created from `_TEMPLATE.md` after its spec is approved.

- The **Files to touch** table is the scope contract: `implement-phase` edits nothing outside it.
- A plan is implemented only after the user approves it.
- Amendments are appended under an `## Amendments` heading with date and reason, never silently rewritten.
